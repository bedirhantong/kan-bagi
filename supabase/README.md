# Supabase kurulumu

1. **Proje oluştur** (supabase.com) ve **Authentication → Providers → Anonymous Sign-Ins**'i aç (misafir girişi).
2. **SQL Editor**'de [schema.sql](schema.sql) dosyasının tamamını çalıştır.
3. **Acil durum alanı (schema.sql'i daha önce çalıştırdıysan):** [03_emergency_patch.sql](03_emergency_patch.sql) dosyasını çalıştır. Yeni kurulumda schema.sql bunu zaten içerir.
4. **Oturumsuz okuma yetkisi ve bildirim tercihleri (schema.sql'i daha önce çalıştırdıysan):** sırayla [04_anon_read_patch.sql](04_anon_read_patch.sql), [05_notification_preferences_patch.sql](05_notification_preferences_patch.sql) [06_hospitals_nearby_limit_patch.sql](06_hospitals_nearby_limit_patch.sql) ve [07_feed_by_distance_patch.sql](07_feed_by_distance_patch.sql) (ana sayfa akışı, yakınlığa göre sıralama) ve [10_blood_donation_points_patch.sql](10_blood_donation_points_patch.sql) (Kızılay kan bağış noktaları tablosu) dosyalarını çalıştır.
4a. **Bildirim bölgeleri (schema.sql'i daha önce çalıştırdıysan):** [12_notification_areas_patch.sql](12_notification_areas_patch.sql) çalıştır. Kullanıcılar yalnızca seçtikleri il/ilçe/hastanelerdeki ilanlar için bildirim alır; hiçbir şey seçmeyen kullanıcıya ilan bildirimi gitmez. Toplam seçim en fazla 10'dur.
4b. **İlan sınırları (schema.sql'i daha önce çalıştırdıysan):** [13_request_limits_patch.sql](13_request_limits_patch.sql) çalıştır. Kullanıcı başına en fazla 3 aktif ilan ve 24 saatte 5 yeni ilan (spam ve bildirim yağmuru koruması).
5. **Test kullanıcıları (yalnızca geliştirme projesinde):** [08_test_users.sql](08_test_users.sql) çalıştır. `donor@test.dev` / `requester@test.dev` (şifre `Test1234!`) ile Apple/Google hesabı olmadan giriş yapabilirsin. `newuser@test.dev` profili boş gelir, kayıt akışını denemek içindir (dosyayı tekrar çalıştırınca yine boşalır).
6. **Kızılay kan bağış noktaları (harita katmanı):** [11_blood_donation_points_data.sql](11_blood_donation_points_data.sql) dosyasını çalıştır (163 nokta: 45 sabit birim, 118 gezici ekip; Android'deki `kizilay_blood_points.json` verisinden üretilmiştir, `tools/import_kizilay_points.py`). Veri Mayıs 2025 haftasına ait 24 il için bir anlık görüntüdür; güncel veriyle yeniden üretmek için script'i yeni JSON ile çalıştır.
7. **Örnek veri:** (Test kullanıcılarını oluşturduysan misafir girişi gerekmez; aksi halde uygulamadan bir kez giriş yap.) SQL Editor'de [02_seed.sql](02_seed.sql) dosyasını çalıştır (story tablosu, örnek hastaneler, story'ler ve 4 örnek ilan). Hastane koordinatları yaklaşıktır; gerçek hastane listesini `hospitals` tablosuna CSV ile import ederek (Table Editor → Import CSV) değiştir.
8. **Apple girişi:** Authentication → Providers → Apple. *Client IDs* alanına iOS bundle id'yi (`com.appvalence.donateblood`) yaz.
9. **Google girişi:** Authentication → Providers → Google. Google Cloud'da *iOS OAuth client* oluştur; *Client IDs* alanına bu iOS client ID'yi yaz ve **"Skip nonce checks"** kapalı kalsın (uygulama nonce gönderir).
10. **iOS yapılandırması:** `donate-blood-ios/donateblood/Config/Secrets.xcconfig` içine URL, anon key, Google client ID ve ters çevrilmiş client ID'yi yaz.
11. **Kaldırılan tablo (schema.sql'i daha önce çalıştırdıysan):** [09_drop_device_tokens_patch.sql](09_drop_device_tokens_patch.sql) çalıştır.
12. **Push (opsiyonel, OneSignal):** OneSignal uygulaması, APNs anahtarı, Edge Function ve Database Webhook adımları [../docs/PUSH_NOTIFICATIONS.md](../docs/PUSH_NOTIFICATIONS.md) dosyasındadır.
    Edge Function kodu: [functions/send-push](functions/send-push) (`deno test -A` ile test edilir).
